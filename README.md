# חברותא – האפליקציה

אפליקציה אמיתית לטלפון. תלמידים נרשמים עם מספר טלפון וסיסמה, מוצאים חברותא, קובעים מפגש בשעה שנוחה לשניהם, ומדברים בשיחת וידאו בתוך האפליקציה. בין לבין מתרגלים במיני-משחקים בסגנון דואולינגו.

## מה יש בה
- **הרשמה עם טלפון וסיסמה.** מספר הטלפון לא מוצג לאף משתמש אחר.
- **בית:** יעד יומי, המפגשים הקרובים עם ספירה לאחור, וכפתור "הצטרף" לשיחה כשמגיע הזמן.
- **חברותא:** התאמה בשני כיוונים ("מי יעזור לי" / "למי אני יכול לעזור"). מוצגים גם הזמנים שמשותפים לשניכם.
- **זמנים פנויים:** כל תלמיד מסמן בפרופיל מתי הוא פנוי (ימים × בוקר/צהריים/אחה״צ/ערב). כשקובעים מפגש, מוצגות רק השעות שהחברותא פנוי/ה בהן, וכוכב ⭐ מסמן שעה שמתאימה לשניכם. החברותא מאשר/ת או דוחה, ואפשר להוסיף את המפגש ליומן עם תזכורת.
- **שיחת וידאו מובנית:** 🎥 בצ׳אט. כולל צלצול אצל הצד השני, השתקה, כיבוי מצלמה, החלפת מצלמה וטיימר.
- **תרגול (מיני-משחקים):** מסלול של 8 שיעורים לכל אחד מ-12 המקצועות. בכל שיעור יש שאלות אמריקאיות, נכון/לא נכון והתאמת זוגות. יש 3 לבבות, קונפטי וצלילים. יש גם "אתגר 60 שניות" עם ניקוד כפול על רצף, וטבלת אלופים.
- **כוכבים, רמות ורצף ימים 🔥:** כוכבים מקבלים מתרגול, ומחברותא שמודים לך על עזרה.
- **פרופיל:** עריכה, התקנה, שיתוף, מדיניות פרטיות, ומחיקת חשבון. מחיקת חשבון היא דרישה של Google Play.

## שני מצבים
- **מצב מקומי** (ברירת המחדל): הכול נשמר רק במכשיר. יש 4 תלמידים לדוגמה שעונים ומאשרים מפגשים. טוב לבדיקה ולהצגה לשופטים.
- **מצב ענן**: אחרי חיבור Firebase (חינם), כל מי שנרשם רואה את כולם, מתכתב ומתקשר באמת.

## שלב 1: חיבור Firebase (פעם אחת, בערך 10 דקות)
1. נכנסים ל-https://console.firebase.google.com ← **Create a project** ← שם `chavruta`. אפשר לכבות את Analytics.
2. **Build → Authentication → Get started** ← בוחרים **Email/Password** ← Enable ← Save.
   (ככה מתחברים עם טלפון וסיסמה בלי לשלם על SMS. האפליקציה הופכת את המספר למזהה פנימי.)
3. **Build → Firestore Database → Create database** ← מיקום `eur3 (europe-west)` ← **production mode**.
4. ב-Firestore ← לשונית **Rules** ← מוחקים הכול ← מדביקים את התוכן של `firestore.rules` ← **Publish**.
5. ⚙️ **Project settings** ← למטה **Your apps** ← הסמל `</>` ← שם `chavruta` ← Register.
6. מעתיקים את מה שבתוך `firebaseConfig = { ... }` לקובץ `config.js`, במקום `null`.
7. **Authentication → Settings → Authorized domains → Add domain** ← הכתובת ב-Vercel (למשל `chavruta-il.vercel.app`).

## שלב 2: העלאה ל-Vercel (מתחילים מכאן)
מעלים את כל התיקייה `chavruta-app` כפרויקט חדש ב-Vercel (Add New → Project). כדאי שיהיה לה דומיין משלה, למשל `chavruta-app.vercel.app`, כי החנויות צריכות אפליקציה שיושבת בשורש הכתובת.

מהרגע הזה כל אחד יכול לפתוח את הקישור בטלפון וללחוץ **"התקנה"**. האפליקציה תופיע על המסך עם אייקון, כמו כל אפליקציה.

## שלב 3: העלאה לחנויות
### Google Play (אנדרואיד)
1. נכנסים ל-https://www.pwabuilder.com ← מדביקים את כתובת האפליקציה ← **Package for stores** ← **Android** ← Generate.
2. מקבלים קובץ zip. בתוכו יש קובץ `.aab` (את זה מעלים לחנות) וקובץ `assetlinks.json`.
3. מעתיקים את ה-`sha256_cert_fingerprints` ואת `package_name` מהקובץ שקיבלתם לקובץ `.well-known/assetlinks.json` שבתיקייה, ומעלים שוב ל-Vercel. בלי זה תופיע שורת כתובת בראש האפליקציה.
4. פותחים חשבון מפתח ב-https://play.google.com/console. העלות היא 25$ חד-פעמי, ובעל החשבון צריך להיות בן 18 ומעלה (הורה או מורה).
5. Create app ← מעלים את ה-`.aab`. צריך גם: את תמונות המסך מהתיקייה `screenshots/`, אייקון (`icons/icon-512.png`), קישור למדיניות הפרטיות (`.../privacy.html`), ושאלון קהל יעד. האפליקציה מיועדת לבני 13 ומעלה.
6. בחשבונות מפתח חדשים, Google דורשת בדרך כלל בדיקה סגורה עם כמה בודקים לפני פרסום לכולם. אז כדאי להתחיל מוקדם.

### App Store (אייפון)
גם כאן PWABuilder מייצר חבילה (בוחרים **iOS**), אבל צריך מחשב Mac עם Xcode וחשבון Apple Developer שעולה 99$ לשנה. עד אז, אייפונים מתקינים דרך ספארי: שיתוף ← "הוספה למסך הבית".

## לפני שמפרסמים
- ב-`privacy.html` להחליף את כתובת המייל `chavruta.app@gmail.com` למייל אמיתי של הצוות.
- שיחות וידאו עובדות ישירות בין הטלפונים. ברוב הרשתות זה עובד, אבל בחלק מרשתות בתי ספר או סלולר זה עלול להיכשל. במקרה כזה אפשר להוסיף שרת TURN (למשל מ-metered.ca, יש להם מסלול חינמי) בקובץ `video.js` בשורה של `ICE`.
- "שכחתי סיסמה" כרגע מפנה לצוות. איפוס דרך SMS אפשר להוסיף בהמשך עם Firebase Phone Auth (בתשלום לפי הודעה).

## קבצים

## חדש בגרסת חצי הגמר
- **שיחת וידאו:** כפתורים 🖊️ לוח ציור משותף (צבעים, מחק, רקע משבצות וצירים, שמירה כתמונה), 🖥️ שיתוף מסך (בדפדפן במחשב; בדפדפני טלפון זה לא נתמך) ו-🎮 משחקים.
- **משחקים בוידאו:** לימודיים (דו־קרב ידע, איקס־עיגול ידע, ארבע בשורה ידע) וגם סתם בכיף (איקס־עיגול, ארבע בשורה).
- **רשת ביטחון:** זיהוי במכשיר של הודעות על מצוקה או חרם, עם קווי סיוע (ער״ן 1201, סה״ר, 105), הודעה מוכנה למבוגר, עצות לחבר, בדיקת מצב רוח יומית (נשמרת רק במכשיר) וכפתור "צריך עזרה?". דיווחים על חרם/מצוקה מסומנים 🆘 בלוח הניהול.
- **קבוצות לימוד:** עד 6 בקבוצה, צ׳אט קבוצתי, וידאו עד 4 במקביל, לוח ושיתוף מסך.
- **עזרה נקודתית:** בקשה קצרה לשיעורי בית; מי שיכול לעזור במקצוע לוחץ "אני עוזר" ונפתח צ׳אט.
- **נושאים:** בתחתית ההרשמה אפשר לבחור נושאים (נגזרות, ספר בראשית, בניינים בלשון…). הקובץ `topics.js`.
- **חברים:** מסלול להכיר חברים לפי תחביבים, רק למי שהפעיל.
- **אימות טלפון בקוד:** במצב הדגמה הקוד מוצג בהודעה על המסך. ל-SMS אמיתי: `window.CHAVRUTA_PHONE_AUTH = true` ב-`config.js`, והפעלת Phone ב-Firebase (Authentication → Sign-in method).

**חשוב לפני העלאה:** להעתיק את `firestore.rules` החדש ל-Firebase → Firestore → Rules ולהציג Publish (בלי זה קבוצות ועזרה נקודתית יחזירו שגיאה).

## גרסת הגמר (v12)
- **שרת TURN**: `ice.js` + `window.CHAVRUTA_TURN` ב-`config.js`. מופעל שרת ציבורי לבדיקות; מומלץ להירשם ל-metered.ca ולהחליף למפתח משלכם.
- **אישור הורה**: תלמידי ז׳–ח׳ חייבים אישור הורה בהרשמה. ההתאמה (חיפוש וחברים) רק בין כיתות קרובות.
- **מצב הדגמה**: במסך הכניסה "🎬 מצב הדגמה (לשופטים)". אפליקציה מקומית עם חשבון ושיחה לדוגמה, בלי שרת. יציאה מהפרופיל.
- **נגישות**: פרופיל › נגישות (גודל טקסט, ניגודיות, פחות אנימציות, רווחי קריאה) + קישור דילוג.
- **מסך פתיחה מונפש** והנפשת כניסה בין לשוניות.
- **דף "איך אנחנו שומרים עליך"** וכפתור 🚩 דיווח בתוך שיחת וידאו.

## תוספות גמר נוספות (v13)
- **סיכום שיעור ודירוג** אחרי כל שיחת וידאו (כוכבים, תגיות, מה למדנו, לחזרה, משימה). נשמר בצ׳אט, כפתור 📒 בראש הצ׳אט.
- **"מה אומרים עליי"** בפרופיל: ממוצע כוכבים ותגיות.
- **מבחנים**: תאריך + תוכנית חזרה מסומנת בבית, וכפתור לחברותא לחזרה.
- **שעות שקטות** (ברירת מחדל לכיתות ז׳–ח׳), **תצוגת הורים** מוגנת בקוד, **כיתה ומורה** (סיכום מצטבר בלי שמות; קוד הדגמה: DEMO1).
- **סרטון הסבר 30 שניות**, **מצב בהיר/כהה/אוטומטי**, חגיגות ליעד יומי ורצפים.
- אין צורך לעדכן את כללי Firestore בשביל התוספות האלה.

## גרסה v14: עוזר AI, שפות, הכשרת מסבירים ועוד
- **עוזר חברותא (AI)**: `api/ai.js` (פונקציית שרת של Vercel) + `assistant.js`. כדי להפעיל: ב-Vercel › Project › Settings › Environment Variables להוסיף `ANTHROPIC_API_KEY` (המפתח מ-console.anthropic.com), ואז Redeploy. אופציונלי: `AI_MODEL`, `FIREBASE_API_KEY` (לאימות משתמשים והגבלה אישית), `AI_REQUIRE_AUTH=1`. אל תשימו את המפתח בקוד האתר או ב-GitHub.
- **שפות והתאמה לעולים**: בפרופיל בוחרים שפות. עולה חדש שמסמן "אשמח למסביר שמדבר את שפתי" רואה קודם מסבירים באותה שפה.
- **הכשרת מסבירים** (תג 🎓 בחיפוש), **תעודת התנדבות** (PNG להורדה), **אתגרי כיתה** (מורה: קוד כיתה + קוד מורה; הדגמה: DEMO1 / 1234), **הודעות קוליות** בצ׳אט (עד 45 שניות).
- **כללי Firestore**: להדביק מחדש את `firestore.rules` (נוספה `classes`) ולפרסם.

## v17: תצוגת מחשב, תרגום מסכי פתיחה, פרטיות
- **תצוגת מחשב** (מסך רחב מ-960 פיקסלים): תפריט צד, עמודים בשתי עמודות (שלוש במסך גדול מאוד), חלונות במרכז.
- **שפות**: מסכי הפתיחה, הכניסה וההרשמה זמינים בעברית, אנגלית, רוסית וערבית (`i18n.js`). שאר האפליקציה בעברית.
- **פרטיות**: `privacy.html` עודכן (עוזר AI, הודעות קוליות, ספקים, אישור הורה). בגיל ז׳–ח׳ נשמר רק אישור ותאריך, לא שם ההורה.
- הודעת "אין אינטרנט", תוויות נגישות לניווט, ושורת "נבנה על ידי תלמידים".
- **ספקי AI** (`api/ai.js`): Anthropic, ואם אין, Gemini (`GEMINI_API_KEY`), ואם אין, Groq (`GROQ_API_KEY`). `vercel.json` מאריך את זמן הפונקציה.
